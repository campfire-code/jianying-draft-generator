# 剪映草稿批量生成器

> 篝火出品 · 收录于篝火 App 应用区

批量生成剪映草稿，打开剪映即可微调

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/jianying-draft-generator/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `jianying-draft-generator_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `jianying-draft-generator_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `jianying-draft-generator_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

1. 在剪映「全局设置 → 草稿位置」里查看草稿文件夹（一般以 `JianyingPro Drafts` 结尾），在本工具参数里选它。
2. 把视频（mp4、mov）或图片（jpg、png）拖进窗口，或点「添加」「文件夹」。
3. 选「怎么生成」：每个素材一个草稿 / 全部拼成一个（按文件名自然顺序，片2 在 片10 前）/ 每 N 个一个。
4. 按需设置画布（横屏、竖屏、方形、跟随第一个素材）、比例不同时的背景（模糊 / 黑边）、图片停留秒数、是否保留视频原声。
5. 可选：背景音乐（mp3 / wav，音量、淡入淡出、不够长时循环）；素材旁边有同名 `.srt` 或 `.txt`（每行一句，平均分配到素材时长）时自动加到字幕轨；「全部拼成一个」时还可加一份整段 SRT。
6. 点「批量处理」。草稿会写到所选草稿文件夹，草稿名默认是素材文件名（可加前缀），文件夹里已有同名草稿时自动加「(2)」，不覆盖。
7. 打开剪映，在草稿列表里找到；没出现就重启剪映。

**支持的剪映版本**：草稿格式没有官方文档，本工具的字段取自开源项目 pyJianYingDraft（Apache-2.0，对照提交 `1e22847`，2026-10-14）。该项目 README 的功能清单把本工具用到的功能（本地视频/图片、视频背景填充、本地音频与淡入淡出）列为在剪映 5.9 与其所称「新版剪映」上都可用，并另说明新版剪映的 `draft_content.json` 往往是加密的，读取模板需要额外读取器（本工具只生成、不读取剪映已有草稿）。

**未核实的部分**（请先用少量素材试一遍）：
- 没有在真实的剪映客户端里验证过打开效果，不确定哪些具体版本能打开；剪映升级后草稿格式可能变化，导致无法打开或打开后缺内容。上游 README 所说「新版」对应的具体版本号，本工具未核实。
- Windows 与 macOS 上的剪映草稿文件夹位置、素材路径写法，只按上游源码的做法写入绝对路径，未在两个系统的剪映里实测。
- 没有写入字幕样式、转场、特效、关键帧等；字幕用上游 `import_srt` 的默认样式（字号默认 5，位置在画面下方）。
- 视频时长和尺寸优先读系统网页引擎，读不到时自己解析 mp4 / mov 文件头；不支持的编码或损坏文件会在列表里报错。
- 全部在本机完成，不联网。

## 验收用例

| 操作 | 应得到 |
|---|---|
| 草稿文件夹选一个空文件夹；拖入 `samples/` 里的 3 张图片；「怎么生成」选「每个素材一个草稿」，开始处理 | 草稿文件夹里出现 `图1（示例）`、`图2（示例）`、`图3（示例）` 三个文件夹，各含 `draft_content.json` 和 `draft_meta_info.json`；每张图时长 3 秒；`图1` 带 2 条字幕（来自同名 srt），`图2` 带 2 条字幕（来自同名 txt） |
| 「怎么生成」选「全部拼成一个」，背景音乐选 `samples/背景音乐（示例）.wav`，草稿名填 `合集` | 生成一个 `合集` 草稿：3 张图共 9 秒，画面轨上依次是图1、图2、图3；背景音乐 5 秒、勾选循环时第二段截到 4 秒结束，首尾淡入淡出 1 秒；字幕共 4 条 |
| 「每 N 个一个」填 2 | 生成 `批量草稿-01`（2 个素材）、`批量草稿-02`（1 个素材） |
| 再次对同一文件夹运行 | 新草稿名自动带 `(2)`，原有草稿文件不变 |
| 不选草稿文件夹就开始 | 提示「还没有选择剪映草稿文件夹」 |
| 在剪映里打开生成的草稿（自行确认，见上方「未核实」） | 能看到对应素材与字幕；打不开时请反馈剪映版本号 |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
